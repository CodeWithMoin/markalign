      How aligned is it, really?

      Two questions, measured apart. Did it match the teacher's marks? And when it was wrong, was it a fixable pattern or just noise? These are from the held-out evaluation — not this one essay.

      Score-agreement is measured with quadratic weighted kappa against held-out human marks. Reasoning-agreement — whether the grade is right for the right reason — is the part the dataset can't verify, and is adjudicated by hand. Run python -m eval.run_eval for the numbers. Method demo on public essay data; not a claim about any specific curriculum.
